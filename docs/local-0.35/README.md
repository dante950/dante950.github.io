# 로컬 0.35 · 몬스타그램과 가게 관리 핸드폰 통일

변경 의도: 가게 관리의 후기·영수증 화면에서도 같은 핸드폰을 보고 있다는 느낌을 유지한다.

기존 정산 전용 CSS 외곽을 사용하던 화면을 몬스타그램의 phone.png 원본과 공통 phoneFrameMarkup으로 바꿨다. 리본·해골 장식, 노치, 상태 표시줄, 제목과 홈·뒤로 버튼을 함께 사용한다. 영수증과 그 오른쪽 진행 버튼은 유지한다. 후기 영역은 같은 화면 높이 438px이며 긴 본문은 내부 스크롤한다.

홈·뒤로 버튼은 진행 중인 재연을 취소하고 핸드폰 홈으로 돌아간다. 중간 이탈은 확인 완료로 처리하지 않고 다시 가게 관리로 들어갈 수 있다. 이미 지급한 팔로워는 그대로다. 완료한 정산의 재열람 역시 기존 보상 정책을 유지한다.

검증 자료: scripts/check-phone-035.mjs, management-1440.png, management-900.png. 이 검사에서는 공통 원화·상태 표시줄, 중간 이탈과 재진입, 두 후기 스크롤·카운트, 영수증·진행 버튼 비겹침과 완료 후 홈 복귀를 확인한다. 기존 check-closing.mjs의 고정 443px 비교는 실제 게시글 높이 기준으로 바꿨다. 기존 전체 마감 브라우저 묶음은 이번에 재실행하지 않았다.

로컬 빌드와 기존 단위·데이터 검사 86개 통과. 공개 배포·Safari·Unity 검증과 Excel·전투 데이터 변경은 하지 않았다.
