# 2026-11-06 마왕 구현 재개 기록

## 기준과 완료 범위

공개 저장소 main의 66b917d8b0283ba4a3b858a0fc07e72ffe00d018(한국 시간 18:12)을 기준으로 이어 작업했다. 기존 outputs/yachacha-pages의 오래된 HEAD와 미커밋 변경은 보존하고, 원격 최신 커밋을 별도 작업본으로 복원했다.

이전 대화에서 확인한 4일차 방문, 별 0/1/2개 지나침과 3개 입장, 실내 등장, 투구 복원·얼굴 노출, 머리 손질·검정 염색, 고블린 자유 미용을 검토했다. 미용 재도전 동선은 [마왕 엔딩 분기](https://app.notion.com/p/409648bf6778806cac95e51dad790bd6)를 기준으로 맞췄다.

## 이어서 수정한 내용

- 본편 마왕 iframe이 pointer-events:none인 story 화면 안에 있어 뒤의 미용실이 클릭을 가로챘다. fullscreen iframe을 body에 배치하고 입력을 받도록 수정했다.
- GAME OVER에서 다시 시작한 뒤 시작 메뉴를 취소하면 4일차 상태가 남았다. 기존 플레이를 먼저 종료해 타이틀로 돌아갈 수 있게 했다.
- 야차 패배 후 미용 재도전은 실패한 미용 단계부터가 아니라 마왕 방문 컷씬부터 다시 진행한다. 야차 재도전은 1페이즈부터 시작한다.
- 마왕 배포 검사에서 무관한 전체 브라우저/마왕부하 검사의 반복을 제거하고, 마왕 미용과 실제 본편 인계 검사로 구성했다. 일반 변경의 기존 전체 검사 job은 보존했다. 마왕 파일 변경 없이 app.js만 바뀐 경우에는 마왕 전용 범위로 분류하지 않는다.

## 검증

- 관련 데이터·단위 검사 28개와 빌드 통과.
- Chromium/WebKit: 별 0/1/2/3 분기, 실내 이동·말걸기, 투구/뿔 복원, 얼굴 15% 노출 야차, 2페이즈 커트·검정 염색·얼굴 1픽셀 오염과 복구, 스티커·제거, 자유 미용과 성공 분기.
- Chromium/WebKit: 패배 후 양쪽 재도전, 실제 클릭·긁기로 시험 전투 3페이즈 승리, 두 종료 경로, 좁은 화면 검사.
- Chromium/WebKit: 테스트 서버에만 완료된 3일차 상태를 주입하고 실제 마감 iframe → 본편 → 마왕 iframe 메시지 경로로 별 2/3개 전달을 확인했다. 실제 클릭, 기록·팔로워 보존, GAME OVER 재시작/취소와 타이틀 복귀를 검사했다. 1~3일차 전체 수동 완주는 아니다.
- 마지막 이전 배포는 마왕 검사·마왕부하 WebKit 검사는 통과했지만 기존 check-browsers의 전투 fixture 대기 시간 초과로 중단되었다. 로컬 재현에서는 해당 전투 진입이 통과한 뒤 별도 시작 메뉴 포커스 검사가 실패했다. 전체 호환성 검사 통과로 기록하지 않는다.

## 남아 있는 원래 프로토타입 범위

야차는 기존 커밋의 클릭·긁기 시험 전투다. 기획서의 가로 참격/균열/거울 반사/6연격이 구현된 최종 마왕 전투가 아니다. 현실 귀환·몬스타그램은 종료 분기를 확인하는 임시 화면이며 최종 컷씬/단체사진/게시글 회상 연출 전체를 완성한 것으로 설명하지 않는다. 외관은 기존 PT 미용실을 사용한 임시 배치이고, 스타 기준 5,000/5,500/6,100과 미용 수치도 기존 시험값을 유지한다. 원본 PNG·Excel·Unity·기존 전투 전용 실험실은 변경하지 않았다.
