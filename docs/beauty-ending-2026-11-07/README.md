# 미용 성공 엔딩 임시 구현 · 2026-11-07

## 의도와 기준
마왕을 꾸민 결과가 미용 결과창에서 끊기지 않고, 동료들과의 작별과 인간세계 귀환, 그동안 만난 손님들의 후기로 이어지는지 확인한다. 사용자 제공 컷씬 분류 페이지의 ‘미용 성공 엔딩’ 대사와 이번 요청의 자동 휴대폰·스크롤 연출을 기준으로 구현했다.

기준: https://app.notion.com/p/411648bf67788060b853e278b98bd354

## 연결 흐름
마왕 2페이즈 미용 성공 → 기존 결과창 → 현재 미용실 → ‘그대에게 큰 상을 내리겠노라.’ → 네 인물 단체사진 → 초록 마법진과 주인공 흡수 → 페이드 → 별과 해질녘 하늘에서 도시로 내려오는 화면·독백 → 기존 휴대폰 홈 자동 등장·몬스타그램 실행 → 실제 완료 손님 후기와 크레딧 → 단체사진 게시글·댓글 → Thank you for playing! → 다시 보기/처음으로.

미용실 대사는 기존 F 입력을 사용한다. 귀환 이후는 자동 진행이며 일시정지·소리 전환이 가능하다. 후기와 12명 크레딧은 하나의 시간표를 공유하여 함께 끝난다. 이메일은 표시하지 않는다. 후기 없는 마왕 바로 시작에서는 크레딧과 단체사진만 나오며 손님 후기를 만들어 넣지 않는다. 다시 보기에서 보상을 지급하지 않는다.

## 리소스와 임시 구현 범위
- 실제 미용 캔버스에서 만든 투명 머리 이미지를 미용실 마왕 몸체와 마지막 단체사진에 그대로 합성한다.
- 마왕 몸체는 사용자 제공 T_Adversary_Phase2.png 사본이다. 원본 파일을 변경하지 않고 렌더링 때 원래 머리 영역을 제외한다.
- 주인공·마왕 부하·커피유령·마법진·휴대폰은 기존 제공 리소스를 재사용한다. 단체사진 배경은 현재 미용실의 벽·바닥·소품만 재구성하여 인물 중복을 피한다.
- return-sky.png는 이번 임시 연출용 AI 생성 픽셀풍 하늘·도시 배경이다. 팀 최종 원화가 아니다.
- 진동·알림·클릭·셔터·귀환 소리는 Web Audio 임시 합성음이다. 사운드 담당자의 최종 음원으로 표기하지 않는다.
- 야차 승리 엔딩, 마왕 전투, 전투 페이즈 전환은 이번 변경 범위에 포함하지 않는다.

## 확인한 범위
관련 자동검사 42개 및 빌드 통과. Chromium에서 완료 상태와 3명 방문 기록을 주입한 뒤 실제 미용실 대사, 커피유령 합류, 사진, 마법진 흡수와 엔딩 진입을 확인했다. 귀환 이후는 시간 지점별 하늘·도시·전화·후기/크레딧·단체사진·댓글·감사문구를 확인하고, 일시정지·다시 보기·처음으로 및 페이지 오류 없음도 검사했다. 이 캡처의 마왕 머리는 검사용 초기 미형 캔버스이며, 전체 미용 손질을 완료한 실제 플레이 결과를 주장하지 않는다. 1~4일차 전체 플레이, 모든 손님 조합의 전수 브라우저 검사 및 Unity 실행 검증은 하지 않았다.

검사용 상태 주입은 localhost 전용 scripts/serve-ending-review.mjs에서만 수행한다. 공개 게임 번들에는 해당 제어 API를 추가하지 않았다. 배포 전 검사는 변경 범위에 맞는 엔딩 브라우저 검사로 한정한다.
