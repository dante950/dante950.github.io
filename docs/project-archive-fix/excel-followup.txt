변경 의도: 대사 작업자가 시뮬레이터에서 작성한 커피 유령·재등장 좀비 문장을 엑셀에서도 확인하고 이어서 편집할 수 있게 한다.

원인: 이전 수정은 전체 프로젝트 JSON을 ZIP에 추가했지만 combatForWorkbook의 두 손님 제외 조건을 유지했다.
변경: 공개 손님 10005/10006의 기존 대사·대화 그룹과 10006의 미용 대사 연결을 내보낸다. 기존 JSON의 workbookExcluded 설정도 호환한다. 새 컬럼이나 임의 전투 페이즈는 추가하지 않는다.
불러오기: 기존 ID를 유지한 엑셀 문장을 우선하며, 누락된 구형 엑셀은 현재 프로젝트의 대사를 보존한다. 그룹 일부가 빠진 파일은 오류로 안내한다.
저장: 통합 프로젝트 복원 결과를 두 엑셀과 JSON 모두에 사용한다. 선택지·사건 매핑과 미용 설정은 계속 JSON에 남으며 Unity 실행 검증을 의미하지 않는다.
검증: 관련 18개 검사, 빌드, Chromium의 실제 ZIP 및 XLSM/XLSX 문장·효과 대조와 독립 엑셀 수정/재입력 통과. WebKit도 XLSM/XLSX 수정·재입력, ZIP 복원·폴더 저장 검사를 모두 통과.
원본 사용자 Excel·기존 공개 대사 본문·수치·인증 코드는 변경하지 않았다.
