# 튜토리얼 진입 시 배포 버전 유지

2026-11-02. 사용자가 최신 메인 주소에서도 이전 퇴장이 보인다고 보고했다. 공개 서버의 튜토리얼 코드는 fb1ce28 최신 상태였으나, 메인 처음부터 버튼과 1·2·3안 링크가 버전 없는 고정 주소를 사용했고 GitHub Pages HTML 응답은 max-age=600이었다. 사용자 브라우저의 실제 캐시 내용은 직접 확인하지 못했으므로 캐시를 확정 원인으로 단정하지 않는다.

빌드 시 튜토리얼 HTML 전체의 내용 해시를 메인 처음부터 주소와 모든 시안 링크에 붙이고, 메인의 시안 선택 페이지 링크에도 해당 페이지 내용 해시를 붙였다. 튜토리얼 변경 시 새 주소로 진입하게 된다. 게임 연출과 수치는 변경하지 않았다.

빌드 통과. Chromium에서 기존 버전 없는 진입 주소에 오래된 HTML을 반환하도록 조건을 만든 뒤 메인 → 영업 시작 → 처음부터를 실제 클릭했다. 새 버전 주소로 진입해 오래된 HTML을 사용하지 않았다. 이어 다시 시작 → 퇴장·마감에서 실제 대사를 넘겨 컵을 든 단독 퇴장 → closed를 확인했다. 시안 선택 페이지와 세 카드의 버전 전달도 확인했고 브라우저 오류0개였다. 첨부 캡처는 메인에서 진입한 실제 새 퇴장 장면이다.
