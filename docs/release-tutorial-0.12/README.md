# 튜토리얼 0.12

변경 의도: 제공된 좌우 뿔 리소스를 직접 골라 맞는 쪽에 붙이게 하고, 이미 본 인트로를 건너뛴 사람은 즉시 첫 손님 여부를 선택하게 한다.

- 임시 TUTORIAL-COFFEE-HORNS-PAIR 스티커를 커피유령 목록에서 제거했다.
- T_hornBig_L은 화면 기준 얼굴 왼쪽, T_hornBig_R은 오른쪽이 정답이다. 각각 15점이며 두 개 모두 있어야 장식 완료다. 반대편·중복·다른 스티커·한쪽만 배치는 완료되지 않는다.
- 기존 attachRegions/stickerIDs 판정을 사용한다. 완료 개수의 기본 1은 유지하고 커피유령 설정에만 attachCount=2를 지정했다. 이는 시뮬레이터 JSON용 설정이며 Excel/Unity 계약 변경이 아니다.
- 판정 구역: 왼쪽 x92 y114 w66 h80, 오른쪽 x162 y114 w66 h80 (320×350 좌표). 원화는 변경하지 않았다. 관련 부탁과 안내도 좌우 배치로 맞췄다.
- 인트로 길게 누르기 스킵은 요약 및 마무리 대사 없이 PT의 손님 받기/안 받기로 직접 이동한다. 안 받기는 기존 몬스타그램 이름 등록으로 이어진다. 예약된 연출과 한숨은 취소한다.

관련 검사 40개와 빌드 29c7759b21d468f1 통과. 전체 미용·전투·정산 브라우저 검사는 반복하지 않는다. 공개 확인 결과는 deployment-result.json에 기록한다.
