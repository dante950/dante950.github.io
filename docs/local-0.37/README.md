# 로컬 0.37 · 정산 연출과 직접 선택 보호

변경 의도: 정산 연출이 핸드폰 탐색 버튼으로 끊기지 않게 하고, 대화를 넘기던 연타가 미용 부탁 수락까지 처리하지 않게 한다.

- 영수증 화면의 홈·뒤로 버튼은 정산 내내 disabled 상태로 표시한다. 0.35의 중간 홈 복귀 허용 정책을 이번 요청으로 대체한다.
- 가게 관리에서 시작한 마지막 정산 버튼은 ‘홈으로 돌아가기 →’다. 영업 종료에서 미확인 정산을 먼저 거치는 경우는 기존 다음 날 진행을 유지하며 ‘다음 날로 →’로 표시한다.
- 최초·상세 미용 부탁 선택은 직접 클릭으로만 진행한다. F·Enter·Space, 키보드가 만든 버튼 클릭, 미용실 iframe의 다음 대사 신호는 선택 단계에서 수락·되묻기를 실행하지 않는다. 선택지 전 문장 바로 보기와 다음 문장은 유지한다.

빌드와 기존 단위·데이터 검사 86개 통과. scripts/check-input-037.mjs에서 정산 내비게이션 잠금, 두 후기 완료와 홈 복귀, 실제 좀비 첫 부탁·상세 부탁·붙이기 부탁에서 양쪽 버튼 포커스와 iframe F 입력 차단, 직접 클릭 시 정상 진행을 Chromium으로 확인했다. 오류 없음. PNG는 실제 로컬 캡처다.

공개 배포·Safari·Unity·전체 본편 완주 검증은 하지 않았다. Excel·대사 본문·보상·전투 데이터 변경 없음.
