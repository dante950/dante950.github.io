# 마왕 외부 등장·말풍선 아이콘 · 2026-11-08

- 스타 0·1·2는 모두 마왕과 부하가 오른쪽으로 지나간다. 부하의 잠깐 뒤돌아보기는 제거했다. 기존 별 평가 대사·게임오버·다시 시작 흐름은 유지한다.
- 스타 3에서만 두 인물 모두 뒷모습 걷기로 입장한다. 마왕 T_Finalboss_walk_back_sheet.png는 180×207, 4프레임이며 제공 GIF와 같은 200ms 간격이다. 부하는 기존 120×176, 4프레임 몸·머리·긴 뿔 레이어와 140ms 간격을 재사용한다. 새 원화를 그리지 않았다.
- 대사 초상화는 제공 7종 PNG의 첫 35×35칸을 사용한다. 원본은 보존하며 추출본만 배포한다. 두 칸을 한 얼굴처럼 축소하거나 마왕 아이콘을 전신처럼 크게 확대하지 않는다.
- 마왕/커피유령/마왕 부하/좀비/취객(Dwarf)/샌즈/양아치두목 이름을 연결했다. 취업 성공 좀비는 제공 좀비 아이콘 공용이며 양아치두목의 새 방문은 추가하지 않았다. 실제 화자 이름이 현재 손님 ID보다 우선한다.
- 공통 초상화 표시 함수가 있는 본편·튜토리얼·엔딩에 적용한다. 원래 초상화가 없는 전투 머리 위 말풍선은 새 UI를 덧붙이지 않았다.

검증: 관련 단위 검사 31개 및 빌드, Chromium 네 스타 분기 확인. 시작 스타만 설정하고 실제 영업 시작·대사 입력으로 진행해 오른쪽 화면 밖 퇴장과 두 인물 각 4프레임을 확인했다. 아이콘 검사는 본편/튜토리얼 표시 함수에 화자를 전달하는 응답 전용 진단코드를 사용한다. 원본 파일·Excel·Unity 계약은 변경하지 않았다. 공개 배포와 추가 브라우저 결과는 deployment-result.json에 기록한다.
