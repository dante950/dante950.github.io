# 0.38 공개 배포 검사

2026-10-25 사용자 승인으로 로컬 0.38을 공개한다. 미용 메모 재타이핑·즉시 반응, 관리 앱 우선 마감, 일차별 성장 위젯, 일반 글과 후기 대화가 대상이다.

빌드 releaseId: 0a5f6cb392c0b019. 단위·데이터 검사 88개 통과. WebKit 검사는 별도 스크립트와 실제 캡처를 보관한다. WebKit의 webkitAudioContext 이름에 맞춰 검사 코드를 보완했으며 제품 코드는 변경하지 않았다. 네이티브 Safari나 Unity 검증은 아니다.

이 Windows headless WebKit 환경은 Web Audio API를 제공하지 않아 오디오 출력 검사를 제외한다. Chromium의 기존 오디오 검사와 구분하며 WebKit 시각 효과·상태 전환 검사는 유지한다.

WebKit 검사 완료: 관리 앱 자동 진입, 정산 1회, N, 실제 일차별 차트, 일반 글·후기 대화·자유 댓글·다음 날 유지, 미용 단계 메모 재생, 빠른 전환, 실제 손질의 꽃·흔들림·중립 복귀 통과.
배포 대상 커밋: a96fd09.
