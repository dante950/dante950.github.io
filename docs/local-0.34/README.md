# 로컬 0.34 · 손님의 부탁을 읽는 속도

변경 의도: 손님의 부탁이 빠르게 지나가지 않도록, 미용을 시작하기 전에 요구 내용을 읽을 여유를 준다.

- 형태·그리기·붙이기 최초/상세 부탁 말풍선은 기존 재생 속도의 0.5배로 표시한다. 개발실의 부탁 대사 미리보기도 같은 속도를 사용한다.
- 부탁 메모는 글자당 23ms → 60ms, 항목 끝 쉼은 130ms → 450ms로 변경했다. 동그라미 뒤 글자가 나오는 순서는 유지한다.
- 문장 바로 보기와 직접 다음 문장으로 넘기는 입력은 유지한다. 일반 등장·전투 대사 속도는 변경하지 않았다.
- 재생 연출만 조정했으며 대화 그룹 CPS 원본·대사 본문·Excel은 수정하지 않았다.

빌드 및 기존 단위·데이터 검사 86개 통과. 로컬 Chromium에서 좀비 부탁의 글자 증가 속도, 바로 보기 이후 수락, 메모 순차 출력을 확인한다. 실제 캡처는 이 폴더에 보관한다. 공개 배포·Safari·Unity 검증은 하지 않았다.
