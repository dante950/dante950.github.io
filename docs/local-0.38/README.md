# 로컬 0.38 · 마감과 손님 후일담

2026-10-25 · 사용자 검토용, 공개 미배포. 공개 기준 커밋은 604424d(0.37), 이 로컬 빌드의 releaseId는 0a5f6cb392c0b019다. 프로젝트 데이터는 v15를 유지한다.

변경 의도: 미용 중에는 방금 한 행동의 의미를 바로 느끼고, 하루 마감에는 정산을 확인한 뒤 손님과 몬스터들의 일상으로 자연스럽게 넘어가게 한다. 모든 게시글이 선택을 요구하지 않도록 읽기만 하는 글도 섞는다.

## 반영 내용

1. 이미 들은 1·2·3단계로 돌아가면 부탁 메모 글자만 다시 타이핑한다. 글자 28ms, 항목 사이 100ms다. 카메라·도구·체크 표시의 첫 등장 연출은 반복하지 않는다. 처음 부탁의 느린 대사와 UI 순차 등장은 유지한다. 빠른 단계 왕복에서는 이전 타이핑을 취소한다.
2. 영업 종료 후 가게 관리 앱을 자동으로 연다. 환영 메시지 450ms → 후기 안내 1450ms → 확인하기 2450ms의 기존 순차 표시를 유지한다.
3. 정산의 마지막 ‘홈으로 돌아가기’를 누르면 완료 안내 후 홈을 표시하고, 읽지 않은 게시글이 있으면 몬스타그램에 N을 붙인다. 정산 전에는 몬스타그램 N을 표시하지 않는다.
4. 그날 정산을 다 본 뒤 가게 관리를 다시 열면 오늘 증가량·누적 팔로워와 완료 안내만 표시한다. 영수증 재생 버튼은 없다. 다음 날은 새 정산을 확인한다. 정산 도중 홈·뒤로 잠금과 보상 중복 방지는 유지한다.
5. 날씨 위젯을 일차별 팔로워 증가 막대 차트·누적 팔로워·1스타까지 남은 수로 교체한다. 실제 완료 방문 기록을 합산한다. 현재 확정 기준은 1스타 5,000명이므로 달성 뒤에는 ‘1스타 목표 달성’을 표시하며 미정인 2스타 기준을 만들지 않았다. 표시 위젯이며 클릭 기능은 없다. 본편 낮 기온 표시는 유지한다.
6. 실시간 만족 표정에는 꽃 7개와 짧은 상승음, 불만족에는 카메라 흔들림과 하강음을 연결한다. 같은 반응 연속 재생은 550ms 간격으로 제한하고 반대 반응은 즉시 전환한다. 표정은 기존대로 900ms 뒤 중립 복귀한다. 모션 감소 설정에서는 흔들림 없이 꽃이 나타났다 사라진다. 효과음은 시연용 합성음이며 기존 소리 설정을 따른다. 개발실 미용 시험 시작에서도 오디오를 준비한다.
7. 선택지 없는 가벼운 일반 글 4개를 추가한다. 1일차 유령 빨래방·슬라임 제과점, 2일차 늑대인간 산책·박쥐 퇴근이다. 기존 선택형 세계관 글과 운세는 유지한다. 자유 댓글과 좋아요는 같은 방식으로 사용할 수 있다.
8. 좀비·샌즈·마왕 부하의 미용/야차 후기 각 분기에 가벼운 선택지 2개와 대댓글을 연결한다. 선택 시 댓글창이 자동으로 열리고 내 댓글 후 손님의 답글이 달린다. 기존 후기 본문은 그대로이며 후일담만 추가했다. 원문이 없는 결과에는 임의 후기를 생성하지 않는다. 하루가 바뀌어 새 마감 화면이 만들어져도 선택·자유 댓글·읽음 기록이 이어진다.

추가 일반 글과 후일담은 AI가 보조한 검토용 문장이다. 사용자 후기 원문·제공 원화·현재 팔로워 보상과 미용 점수는 변경하지 않았다. 선택 댓글에는 보상이 없으며, 자유 댓글에는 자동 답글을 달지 않는다. 같은 플레이에서 유지하는 상태로, 새 플레이나 새로고침을 넘는 영구 SNS 저장은 아니다.

## 검토 동선

- `http://127.0.0.1:4173/closing.html`: 영업 종료 → 가게 관리 → 확인하기 → 후기/영수증 → 홈 → 위젯/N → 가게 관리 재진입 → 몬스타그램 일반 글·후기 선택.
- `http://127.0.0.1:4173/`: 개발실 → 미용 → 손님 선택 → 이 설정으로 미용 시험. 각 부탁을 수락한 뒤 단계 왕복과 실제 손질 반응을 확인한다.
- 실행 중인 로컬 서버는 저장소에서 `node scripts/serve-local.mjs`로 연다. 코드 수정 뒤에는 `node scripts/build.mjs`가 필요하다.

## 확인한 범위

- 최종 빌드 성공, 단위·데이터 검사 88개 통과.
- `scripts/check-local-038.mjs`: Chromium에서 두 일차의 관리 앱 자동 진입, 정산 재진입 방지, N, 실제 증가량 위젯, 비선택 글, 선택 댓글→대댓글·자유 댓글·다음 날 유지 확인. 실제 미용 단계 왕복·빠른 전환, 가위/발모제 입력 후 꽃·흔들림·중립 복귀 확인. 소리 켜짐에서 Web Audio 노드의 재생 시작, 꺼짐에서 미생성 확인. 꽃이 거울 뒤에 가려지는 문제를 실제 캡처로 찾아 수정했다.
- `scripts/check-social-restore-038.mjs`: 완료 방문 기록을 넣은 새 본편 iframe에서 후기 선택·일반 글 선택·자유 댓글·읽음 구분 복원 확인. 기본 시험값과 다른 기록을 넣어 일차별 증가량 및 남은 수 계산을 확인했다. 전체 본편 전투 완주는 아니다.
- `scripts/check-closing.mjs`: Chromium/WebKit에서 이틀 마감, 강제 패배 재도전 후 제안 패배, 별 기준 미달, 실제 속도의 집계와 후기 스크롤 통과. 이후 수정은 미용 효과 레이어·개발실 오디오 준비이며 마감 코드는 동일하다.
- 페이지 오류 없음. 실제 청감 품질·초심자 사용성, 네이티브 Safari, Unity 실행 및 전체 본편 완주 검증은 아니다. 신규 미용 효과의 WebKit 검사는 공개 승인 후 배포 검사에서 진행한다.
