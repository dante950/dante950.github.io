# 로컬 0.31 · 핸드폰 홈과 소셜 대화

변경 의도: 앱이 설치된 개인 핸드폰처럼 보이게 하고, 선택과 자유 댓글로 직접 소통하는 느낌을 만든다.

- 상태 표시줄(시각·통신·Wi-Fi·배터리 장식)과 바탕화면, 동일 66×66 앱 아이콘. 상태 표시줄은 실제 장치 상태를 읽지 않는 게임용 표시다.
- 오른쪽 설명 삭제, 우측 하단 영업 종료 버튼만 유지.
- 선택 시 댓글 시트 자동 열림 → 0.35초 뒤 플레이어 댓글 → 1.5초 뒤 작성자 답글. 자유 댓글은 최대 300자, 답글 없이 표시하며 공백 입력은 무시한다.
- 가게 관리의 매장봇 메시지 두 개 자동 도착 → 확인하기 → 기존 손님 후기/영수증 재연. 미확인 종료 시 정산 선행 규칙 유지.
- 1·2일차 운세 게시글은 시연용 초안, 실제 보상 영향 없음.
- 화면에 35% 이상 드러난 글 또는 댓글창을 연 글을 본 것으로 기록한다. 다음 날에는 새 글을 먼저, 지난 영업일에 본 글 앞에 ‘여기까지 확인했어요’를 표시한다. 댓글·선택·읽음 기록은 같은 본편의 다음 날에 전달하며 새 플레이/다시 보기는 초기화한다. 브라우저를 닫은 뒤 영구 보관하는 저장 기능은 아니다.

빌드·86개 단위/데이터 검사 통과. Chromium에서 앱 규격, 자동 댓글 순서, 자유 댓글의 문자 표시와 자동 답글 없음, 매장봇 확인 버튼, 2일차 읽음 표시와 댓글 유지 확인. 실제 로컬 화면은 home.png, comments.png, management-chat.png, seen-divider.png다. 공개 배포·Safari·Unity·Excel 변경 없음.

실행 중인 로컬 주소: http://127.0.0.1:4173/closing.html
재실행은 저장소에서 `node scripts/build.mjs`, `node scripts/serve-local.mjs`.
