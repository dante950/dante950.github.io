# 튜토리얼 0.11 공개 배포

변경 의도: 발표 중 선택과 소환·5일차 방문 예고를 같은 무대에서 자연스럽게 이어 보여준다.

0.10~0.11 변경을 공개한다. A/D 선택 및 F 확정, PT 안에서 손님 수락·거절, 스크린 상승 후 부하의 중앙 복귀, 영업 안내 이미지 단계 전환, 두 번째 한숨 위치 보정, 부하에서 마법진으로 내려가는 소환 연출, 달력에서 마왕으로 내려가는 5일차 예고를 포함한다.

사용자 요청으로 전체 검사는 반복하지 않고 발표 검사 13개 및 빌드만 수행했다. 빌드 3f3590bda9df7334. 이미 직전 작업에서 로컬 주요 분기·스크롤을 확인했다. 공개 배포 결과는 deployment-result.json에 기록한다.

이후 수정은 별도 로컬 승인 대기 없이 공개 주소에 바로 반영한다. 인트로 파일만 변경된 push에서는 발표 검사만 수행하고, 관련 없는 전체 브라우저 검사를 생략하도록 GitHub Actions를 조정했다. 수동 실행과 다른 코드 변경에 대한 기존 검사 경로는 보존했다.

Excel·게임 수치는 변경하지 않았다. 전체 게임 완주 및 Unity 검증을 의미하지 않는다.
