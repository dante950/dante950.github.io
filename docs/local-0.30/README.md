# 통합 0.30 · 미용과 몬스타그램 로컬 검토본

사용자 기획의 목적은 손님의 부탁을 먼저 듣고 손질을 시작하게 하는 것, 그리고 미용실 밖 몬스터 사회와의 대화를 하루 마감의 휴식으로 만드는 것이다. 기존 통합 저장소에서 구현했으며 공개 배포는 하지 않았다.

- 최초 cut/draw/attach 부탁: 작업 UI 숨김 → 손님 줌인 → 대사·되묻기·수락 → 줌아웃 → 단계 버튼·도구·메모·하단 UI 순차 등장. 들었던 단계로 돌아갈 때 반복하지 않는다. 메모는 항목 표시 뒤 글자를 순차 출력한다.
- 최근 행동의 점수 변화와 실패 진입/해제를 표정으로 짧게 표시하고 0.9초 뒤 무표정으로 돌아간다. 최종 완성은 무표정으로 시작해 기존 종합 판정을 드러낸다. 점수·영역·보상 수치 변경 없음.
- 영업 중 핸드폰 금지, 마지막 손님 퇴장 뒤 마감 핸드폰. 홈의 몬스타그램과 가게 관리로 진입한다. 낮 22~28도/밤 13~18도 정수 난수는 같은 실행의 해당 일차 동안 유지한다.
- 일반 글 2개는 시연용 초안. 선택 → 플레이어 댓글+작성자 답글, 한 글에 1회, 보상 없음. 댓글 아이콘은 핸드폰 내부 아래에서 시트를 올린다. 본문 더 보기와 댓글창은 별개다. 다음 날에도 선택을 유지한다.
- 가게 관리는 기존 후기·팔로워·스타 재연이다. 확인 후 홈으로 복귀하며, 미확인 상태에서 종료하면 재연을 먼저 거친다. 다음 날·DAY 3 감상 흐름과 실제 방문 완료 1회 지급을 유지한다.
- 실제 손질한 머리를 새 후기 원본에 합성한다. 마감 독립 시험은 기본 머리 예시를 사용한다. 사진별 합성 앵커는 시연용 배치이며 Unity 배치 규약은 아니다.

## 원본과 미확정 사항

기획: https://app.notion.com/p/403648bf677880ea8afaf6edb41e6475

후기 본문·이미지: https://app.notion.com/p/403648bf6778803c987fe9ac906a6fe3

제공된 분홍 핸드폰/리본·해골 장식 PNG를 사용했다. 후기 배경 6장은 위 Notion의 렌더링 이미지에서 받은 WebP 사본이며 새 원화나 AI 생성 그림이 아니다. `public/media/social/*-sample-head.png`는 기존 시뮬레이터 렌더러에서 추출한 기본 상태 예시다. 본편은 실제 결과의 머리 PNG를 전달한다.

좀비 아이디는 원고의 Dubuk_zom을 임시 사용한다(UI 이미지의 Duduk_zom과 불일치). 미용 실패 후 야차 없는 종료 등 원문 없는 분기는 미작성으로 표시한다. 일반 글의 문장·선택 횟수·보상 없음, 사진별 머리 위치는 검토 대상이다. 기존 후기 미용 성공 기준은 현재 실행의 40점 이상을 따른다. 강제 야차 손님이라도 미용 성공이면 성공 후기를 사용한다.

## 확인 범위

빌드와 단위/데이터 검사 86개 통과. 로컬 Chromium에서 세 손님의 부탁 집중·수락 후 UI, 되묻기, 단계 왕복, 실제 가위/발모제 조작 직후 표정·중립 복귀 및 결과 공개, 댓글 선택·답글·시트 영역, 날씨 유지, 정산 홈 복귀, 종료 전 정산 강제, DAY 3까지 확인했다. 별도 본편 iframe 연결 검사는 완료 기록을 대입한 시험이며 실제 전투 전체를 플레이한 것이 아니다.

실제 로컬 캡처: beauty-request.png, beauty-tools.png, phone-home.png, phone-comments.png, management.png. review-composition.png는 사진 6개의 합성을 비교하기 위한 검사용 화면이다.

Unity 빌드 실행, Excel 원본 수정, 네이티브 Safari 및 공개 배포는 하지 않았다. 프로젝트 데이터 v15 유지. 기존 전투 전용 실험실도 수정하지 않았다. Notion 스크린샷 직접 첨부는 업로드 연결 오류로 완료하지 못했다.

## 로컬 실행

저장소 루트에서 `node scripts/build.mjs`, `node scripts/serve-local.mjs`를 실행한다.

- 본편: http://127.0.0.1:4173/
- 마감부터 시험: http://127.0.0.1:4173/closing.html

검사: `node --test tests/*.test.mjs`, 실행 중인 로컬 서버에 대해 `node scripts/check-social-local.mjs`, `node scripts/check-social-detail.mjs`.
