# 통합 0.37 배포 준비 · 2026-10-24

사용자가 로컬 0.30~0.37의 반영 결과를 확인한 뒤 공개 배포를 요청했다.

## 변경 목적과 동작

손님의 최초·상세 부탁에 집중하도록 줌과 UI 순차 등장, 느린 부탁 메모와 말풍선을 연결했다. 행동 직후의 짧은 표정과 최종 결과 표정을 구분한다. 미용 도구 연습과 강제 되묻기 교육은 현재 본편에서 제외했으며 선택지가 나오면 직접 클릭해야 진행한다.

하루 마감에 핸드폰 홈에서 몬스타그램과 가게 관리를 확인한다. 날씨 위젯, 같은 크기 앱, 읽지 않은 게시글 N, 일반 게시글과 선택형 운세, 자동 댓글·대댓글, 자유 댓글, 다음 날 읽음 구분을 제공한다. 가게 관리는 메시지 두 개와 확인 버튼이 순서대로 나오며, 같은 핸드폰 외형으로 후기·영수증을 보여 준다. 영수증 옆 버튼으로만 진행하고 하단 홈·뒤로는 잠근다. 종료 후 목적지에 맞게 홈으로 돌아가기 또는 다음 날로를 표시한다.

제공된 후기 원본과 손질한 머리 합성을 사용한다. 일반 게시글·운세 문장은 초안이다. 실제 팔로워 지급은 방문 완료 때 한 번이고 정산은 표시 재연이다. 자유 댓글과 읽음·선택 기록은 같은 플레이의 다음 날로 이어진다.

## 데이터와 범위

프로젝트 v15 및 Excel 원본, 전투 데이터는 변경하지 않았다. 미용 튜토리얼 전용 몬스터는 별도 후속 기획이다. Safari 실기기와 Unity 실행 검증은 아니다.

배포 대상 릴리스: f1911ae581b1e4c9. GitHub 원격 main의 자동 Pages 배포를 사용하며 강제 푸시는 사용하지 않는다.

## 배포 상태

현재 명령 실행 환경의 네트워크 제한으로 GitHub fetch가 실패했다. sandbox_approval=false 정책이 권한 확장 요청도 거절했다. 아직 원격 push와 GitHub Actions 배포 완료를 확인하지 못했으며 공개 배포 완료로 취급하지 않는다.

## 배포 전 검사

- 빌드 성공, 단위·데이터 검사 86개 통과.
- Chromium / WebKit: 좀비·샌즈 미용 말풍선과 메모, 입 모양, 발모제, 형태 비가역성, 그리기·붙이기 되돌리기와 판정 검사 통과.
- Chromium / WebKit: 하루 마감 2일차 흐름, 강제 재도전·제안 패배, 별 기준 미달, 실제 속도의 스크롤·집계 통과.
- Chromium / WebKit: 미용 대사 세 단계·상세 부탁·다시 듣기·편집 반영, Excel 두 형식의 연결 일치와 여러 문장의 마지막 선택지 통과.
- Chromium / WebKit: Excel 왕복 저장과 VBA 보존, 본편 전투 진입, 이미지 재시도, 방문자 저장 잠금 통과.
- Chromium / WebKit: 마왕 부하 뿔·다크서클·결과 및 복귀 통과.
- WebKit 추가 확인: 동일 앱 크기, 선택 댓글→답글, 자유 댓글, 가게 관리 순서, 운세, 다음 날 읽음 구분·댓글 유지, 영수증 홈/뒤로 잠금, F/Enter/Space 차단과 직접 클릭 통과.

기존 검사 스크립트의 고정 대기와 연속 클릭을 새 부탁·메모 연출에 맞춰 조정했다. 결과 화면의 자동 종료와 스크린샷 인코딩이 겹칠 수 있어 결과 복귀 검사는 현재 화면을 확인한 후 클릭하도록 수정했다. 런타임 코드를 검사에 맞춰 바꾸지는 않았다.

실제 Safari 기기·Unity 실행·전체 전투 완주·공개 웹사이트 검증은 포함하지 않는다. 실제 로컬 WebKit 캡처와 진단 결과는 이 폴더에 보관한다.
