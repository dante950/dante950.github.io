# 커피 유령 대사 편집 연결

개발자 실험실 → 대사 → 커피 유령(10005)에 튜토리얼에서 실제 사용하는 23개 대화 묶음, 35개 문장을 추가했다. 등장·착석 말걸기·단계별 부탁/네? 1회/네? 2회·가위와 발모제 반응·미완료 안내·야차 제안·대련 대사·퇴장 인사를 포함한다.

공통 원본은 src/tutorial/dialogues.js다. 빌드할 때 프로젝트에 빠진 대화를 추가하며, 이미 편집한 문장과 빈 그룹은 덮어쓰지 않는다. 개발실의 문장·화자·미리보기 및 프로젝트 JSON 저장을 사용한다. 기존 저장 권한과 공개판/브라우저 작업본 분리는 유지한다. 공개 튜토리얼에 수정 내용을 반영하려면 기존처럼 편집한 프로젝트 JSON을 배포 데이터에 반영한다. 일반 영업 시작은 공개판이다.

커피 유령은 대사 전용 편집 항목으로 본편 일정·미용/야차 일반 손님 목록에 추가하지 않는다. Excel 내보내기에서 전용 그룹을 제외하고, 다시 가져올 때 프로젝트의 커피 대사를 보존한다. 원본 Excel 및 원화 수정 없음.

튜토리얼은 같은 프로젝트의 문장을 읽는다. 일반 대화의 글자 효과·속도·자동 진행 설정과 전투 대사 전달을 연결했다. 미용 요청은 3단계 되묻기/수락 방식을 유지하며 여러 문장은 같은 요청에서 줄바꿈으로 표시한다. 미완료 안내의 {미완료요구}는 실제 부족한 항목으로 치환한다. 전투의 컵 복귀 효과와 타이밍은 유지한다. 마왕 부하의 전투 조작 안내는 별도 고정 튜토리얼이며 이번 편집 항목에 포함하지 않는다.

검증: 관련 34개 검사 통과. 로컬 Chromium에서 커피 선택, 23개 사건, 실제 문장 편집→대화 미리보기, 타 손님 전환, 미용 목록 전환, 수정한 프로젝트를 주입한 실제 튜토리얼 등장/글자 색, 미용 부탁과 네? 두 차례를 확인했다. 브라우저 오류 없음. 전체 본편 완주·Unity 실행은 범위 밖이다.

- coffee-dialogue.png: 실제 개발실 등장 대사 편집 화면
- tutorial-edited-preview.png: 검증용으로 수정한 문장/색이 실제 튜토리얼에 표시된 화면(공개 기본 대사를 변경한 것은 아님)

배포 전체 검사에서 과거 2일 일정·고정 튜토리얼 주소·배열 위치를 가정하던 검사 3개를 발견했다. 현재 3일 일정, 버전이 붙은 3안 진입, ID로 손님을 찾는 기대값으로 갱신한 뒤 전체 단위/데이터 검사 159개가 통과했다.

브라우저 CI 범위: 전체 묶음에서 과거 손님 3명 가정(현재 4명)과 별도 전투 fixture의 진입 대기 시간 초과가 확인되었다. 손님 수 검사는 현재 ID 목록으로 수정했다. 전투 fixture의 시간 초과는 이번 대사 편집 기능의 오류로 재현되지 않았다(로컬 WebKit에서 세 몬스터 진입 확인). 기존 전체 검사는 일반 변경에 계속 유지하고, 대사 편집 관련 파일만 변경한 경우에는 check-coffee-dialogue.mjs의 Chromium/WebKit 편집→미리보기→튜토리얼 반영 및 되묻기 검사를 배포 조건으로 사용한다. 전체 데이터/단위 검사는 그대로 수행한다.
