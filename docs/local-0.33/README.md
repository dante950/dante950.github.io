# 로컬 0.33 · 읽지 않은 게시글과 매장봇 순차 안내

변경 의도: 몬스타그램에 확인할 이야기가 남았는지 홈에서 알 수 있게 하고, 매장봇 안내를 읽은 뒤 확인 버튼을 발견하게 한다.

- 홈의 몬스타그램 앱 오른쪽 위에 N 배지를 추가했다. 현재 일차에 볼 수 있는 일반 글·운세·손님 후기 중 읽지 않은 글이 하나라도 있으면 표시한다. 기존 읽음 기록을 사용하며 앱을 열었다는 이유로 전체를 읽음 처리하지 않는다. 다음 날에도 이전 읽음 기록과 새 게시글 목록으로 판단한다.
- 매장봇의 첫 안내(진입 후 0.45초), 두 번째 안내(1.45초), 확인하기(2.45초)를 분리했다. 버튼은 짧게 위로 나타난다. 도중에 홈으로 돌아가면 이전 화면의 예약 출력이 끼어들지 않는다.
- 기존 전체 흐름 검사에서 가게 관리 배지 확인 범위를 해당 앱으로 한정했다. 몬스타그램에 남은 N을 가게 관리 미확인으로 오인하지 않도록 한 검사 수정이다.

로컬 빌드 성공. 기존 단위·데이터 검사 86개 통과. scripts/check-social-033.mjs에서 초기 N, 일부만 본 뒤 N 유지, 전체를 본 뒤 N 해제, 안내 두 개와 버튼의 각각 1초 간격, 도중 이탈 시 예약 출력 차단을 Chromium으로 확인했다. 페이지 오류 없음. 기존 전체 흐름 브라우저 검사 묶음은 이번에 재실행하지 않았다.

공개 배포·Safari·Unity 검사는 하지 않았다. Excel·보상·전투 로직 변경 없음. PNG는 실제 로컬 화면 캡처다.
