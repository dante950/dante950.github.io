# 2026-11-08 전환 문구 제거·기사 읽기 수정

사용자 피드백: 페이즈가 바뀔 때 화면 가운데 뜨는 문구 제거. 마왕 후일담은 두 게시글이 아닌 한 게시글이며, 전문을 천천히 자동 스크롤해 읽을 수 있어야 한다.

- 전환의 중앙 제목만 제거했다. 전투 정지·페이드·체력 경계·패턴은 유지한다.
- 기획서의 두 문단을 하나의 마계일보 게시글로 합쳤다. 본문과 댓글 문구는 현재 기획 내용을 유지한다.
- 4.5초 처음 읽기 → 렌더링된 전체 기사 높이와 글자 수에 따른 자동 스크롤 → 끝에서 5초 읽기 → 댓글 → 마지막 단체사진 → 감사 문구. 일시정지와 다시 보기도 스크롤에 적용한다.
- 해피엔딩 대사·기사·댓글 개편은 아직 제안 단계다. 주인공의 귀환 선택, 마왕의 인정과 사과, 본모습의 수용, 작별사진의 동기를 보강하는 방향을 제안한다. 사용자 확인 없이 원문 기획서나 엔딩 대사는 바꾸지 않았다.
- 이 대화에서 영상 첨부는 확인되지 않았다. 영상 분석 결과를 주장하지 않는다.

검증: 관련 단위 검사 20개와 빌드, Chromium의 본편 실패→전투→승리→엔딩 연결, 기존 미용 성공 엔딩 회귀 확인. 기사 직접 진입 검사는 검사용 초기 상태와 시간 이동을 사용하며 실제 경과 시간에서 자동 진행·일시정지·본문 끝·댓글 순서·다시 보기 초기화를 Chromium/WebKit에서 검사한다. 전체 플레이 완주나 Unity 검증이 아니다.
