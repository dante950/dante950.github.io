# 2026-11-08 마왕 시작 분기

요청: 영업 시작에서 마왕부터 선택하면 상단에 네 분기를 고르는 메뉴를 둔다.

- 상단 마왕 분기에서 선택 후 시작: 1페이즈 미용부터 / 2페이즈 미용부터 / 미용 성공 / 야차 승리.
- 1·2는 등장 컷씬을 생략하고 해당 페이즈 부탁·미용 도구로 바로 진입한다.
- 미용 성공은 기본 미형 모습을 사용해 “그대에게 큰 상을 내리겠노라.”부터 기존 귀환 엔딩을 재생한다. 실제 손질 성공 기록을 만들지 않는다.
- 야차 승리는 기존 전투 렌더러에 최종 패배 상태만 준비하고 “……내가 졌다.”부터 승리 표시·고블린 귀환 엔딩으로 이어진다. 일반 전투의 HP·패턴에는 적용되지 않는다.
- 분기 시작은 새 세션이다. 이전 대화·전투·엔딩을 정리하고 손님 기록·팔로워를 새로 시작한다. 저장 잠금 해제가 필요하지 않다. 다른 손님·일반 순차 플레이에서는 메뉴를 숨긴다.

검증: 관련 67개 단위 검사 및 빌드 성공. Chromium/WebKit에서 화면의 영업 시작→마왕부터→분기 선택·시작을 실제 조작해 네 경로를 확인했다. 미용 대화 도중 분기 변경, 두 엔딩 iframe 인계, 다른 손님에서 숨김, 성공·승리 바로 보기로 방문 기록을 만들지 않는 것도 검사했다. 검사용 상태 주입 없이 공개 UI로 진입한다. 모든 미용 수동 완주·전체 야차 수동 완주·Unity 검증은 아니다.

참고 영상: https://youtu.be/NWVAw8EOzLY . 엔딩 스토리 개편은 이전 제안 단계이며 이번 메뉴 수정에서 대사나 기사 내용을 바꾸지 않았다.
