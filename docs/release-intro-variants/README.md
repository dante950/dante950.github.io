야차 경고 뒤 몬스터들이 야차를 즐기며 승리가 이름을 알릴 기회가 된다는 두 대사를 추가했다. 해당 구간은 휴대폰 들기·윙크·브이·1회 플래시 동작이다. 기존 1·2안은 유지하고 3안 스킵은 소개 대사로 바로 연결한다. 관련 22검사, 빌드 및 Chromium에서 3안의 10개 대사와 선택→거절→닉네임 흐름, 셀카 화면을 확인했다. 전체 게임 검사는 반복하지 않았다.
