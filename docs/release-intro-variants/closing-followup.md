# 튜토리얼 마감 연결 복구

2026-10-31

원인: 튜토리얼 호스트가 가입 안내를 registration:true, autoClose:false로 요청했고, 가입 확인 이벤트를 받으면 완료 여부와 관계없이 본편으로 이동했다.

수정: 완료된 커피유령 방문(마감 미리보기 포함)은 가입 확인 뒤 마감 연출로 이어진다. 후기·영수증 확인 후 핸드폰 홈과 몬스타그램을 열 수 있으며 사용자가 영업 종료를 선택하면 다음 날로 간다. 실제 튜토리얼 거절은 후기 없이 기존 본편 연결을 유지한다. 미리보기는 기존 완료 방문 생성 함수를 사용한다.

검증: 관련 마감·후기 검사 22개와 빌드 통과. Chromium에서 세 시안의 닉네임·마감 바로가기 → 가입 → 커피유령 후기/영수증 → 홈 → 몬스타그램 → 좋아요·댓글 → 가게 관리 재입장을 확인했다. 팔로워 100 유지와 정산 재연 없음 확인. 명시적 스킵은 본편으로 이동함을 확인했다. 전체 게임 완주와 브라우저 행렬은 반복하지 않았다.
