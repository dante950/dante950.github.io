# 로컬 0.36 · 날씨 위젯과 미용 튜토리얼 분리

변경 의도: 홈 화면을 사용자가 위젯과 앱을 배치한 핸드폰처럼 보이게 하고, 현재 손님에게 붙어 있던 미용 교육을 향후 전용 몬스터 기획으로 분리한다.

- 날씨를 제목·현재 밤 기온·낮 기온으로 나눈 둥근 블록에 넣었다. 배경, 테두리, 옅은 그림자로 바탕화면과 구분한다. 클릭·드래그 기능은 없다. 기존 랜덤 기온과 같은 날 유지 규칙은 그대로다.
- 현재 본편의 미용 도구 연습과 강제 되묻기 안내를 비활성화했다. 등장 대화 이후 손님의 첫 부탁으로 바로 이어지며 ‘네?’ 상세 부탁과 ‘알겠습니다’는 자유롭게 선택한다.
- 이전 교육 구현은 향후 검토용으로 보관하며 새 튜토리얼 몬스터나 대사는 아직 만들지 않았다. 전투 튜토리얼과 기존 미용 도구·느린 부탁 출력은 유지한다.

로컬 빌드와 기존 단위·데이터 검사 86개 통과. scripts/check-home-036.mjs에서 날씨 블록의 비조작·앱/하단 버튼 비겹침, 실제 본편 좀비 등장→대화→첫 부탁, 연습과 되묻기 강제 안내 미노출, 수락 후 미용 시작, 붙이기 단계의 선택적 상세 부탁을 Chromium으로 확인했다. 페이지 오류 없음. weather-widget.png와 first-request.png는 실제 로컬 화면이다.

미배포 로컬 검토본이다. Safari·Unity·전체 본편 완주 검증은 하지 않았다. Excel·대사 본문·보상·전투 데이터 변경은 없다.
