## 변경 의도

미용 중에는 손님이 무엇을 부탁하는지 먼저 집중해서 듣고, 직접 손질한 행동에 대한 반응을 바로 이해할 수 있게 한다. 몬스타그램은 하루의 성과를 확인하는 기능에 더해, 손님들이 살아가는 몬스터 사회와 짧게 교류하는 시간으로 확장한다. 영업 중에는 손님 응대가 끊기지 않도록 하고, 하루 마감에 핸드폰을 확인하도록 흐름을 모은다.

## 1. 최초 미용 요구와 UI 등장

- 형태 만들기, 색·무늬 꾸미기, 장식 붙이기의 <b>각 최초 요구 대사</b>에서는 작업 UI를 숨기고 손님과 말풍선에 집중한다.
- 손님에게 살짝 줌인하고, 대사를 모두 듣고 수락하면 원래 작업 구도로 줌아웃한다.
- 상단 단계 버튼 3개를 차례대로 표시한 뒤 좌측 부탁 메모와 우측 도구함, 하단 작업 버튼을 순차 등장시킨다.
- 한 번 안내받은 단계로 자유롭게 돌아갈 때는 최초 연출을 반복하지 않는다. 기존 네? 상세 부탁, 알겠습니다, 다시 듣기는 유지한다.
- 부탁 메모는 항목별로 <b>○ 표시 등장 → 문장 타이핑 → 다음 ○ 표시 → 다음 문장 타이핑</b> 순서로 보여준다.
- 하단 버튼의 구체적인 움직임과 각 연출 시간은 시뮬레이터에서 검토하는 임시값이다.

## 2. 미용 행동 반응과 최종 결과

- 내부 미용 판정과 최종 결과의 연출을 구분한다.
- 만족에 해당하는 행동은 잠깐 웃은 뒤 기본 표정으로 돌아온다.
- 불만족에 해당하는 행동은 잠깐 찡그린 뒤 기본 표정으로 돌아온다.
- 관련 없는 행동은 기본 표정을 유지한다.
- 최종 미용 결과에서는 기본 표정으로 시작한 뒤 최종 만족도에 맞는 표정으로 바뀐다.
- 이번 연출 고도화만으로 기존 몬스터별 점수·목표 영역을 임의 변경하지 않는다. 행동 반응의 구체적 평가와 반복 간격은 로컬 시연에서 확인한다.

## 3. 하루 마감과 핸드폰 홈

- 영업 중에는 몬스타그램을 열지 않는다. 첫 손님을 배웅하면 두 번째 손님이 바로 이어진다.
- 마지막 손님을 배웅한 뒤 영업 종료 안내를 거쳐 핸드폰 홈을 표시한다.
- 홈에는 <b>몬스타그램 / 매장관리</b> 앱과 <b>마왕 방문까지 남은 일수</b>를 표시한다.
- 튜토리얼의 낮 화면은 태양과 <b>22\~28도 랜덤</b>, 마감의 밤 화면은 달과 <b>13\~18도 랜덤</b>이다.
- 기온은 화면을 다시 열 때마다 바뀌지 않도록 같은 일차·낮밤 안에서는 유지하는 방식으로 우선 시연한다.
- 몬스타그램은 자유 스크롤과 교류, 매장관리는 당일 후기와 팔로워·별 정산을 담당한다.

## 4. 몬스타그램 피드와 댓글

- 기존 손님 후기 외에 몬스터 세계의 사회·일상·문화를 보여주는 일반 게시글을 넣는다.
- 별도 게시글 상세 페이지로 들어가지 않고 피드에서 읽는다. 긴 본문만 펼치기를 제공한다.
- 게시글 아래 선택지는 본문이나 댓글창을 펼치지 않아도 보인다.
- 선택지를 누르면 그에 맞는 플레이어 댓글과 상대의 대댓글이 자동으로 달린다.
- <b>댓글 아이콘을 누르면 핸드폰 화면 하단에서 댓글창이 위로 슉 올라온다.</b> 피드 위에 겹쳐지는 패널이며 별도 화면 전환이 아니다.
- 자유 댓글 입력과 게시를 제공한다. 자유 댓글에는 자동 대댓글을 달지 않는다. 시연에서는 300자까지 입력하며 같은 플레이의 다음 날에도 유지한다.
- 일반 게시글·선택지·대댓글 원문은 아직 확정되지 않았다. 시뮬레이터에는 시연용 초안을 구분해 넣고, 우선 보상 수치에 영향을 주지 않는 1회 선택 방식으로 시험한다.
- 선택 직후 댓글창이 자동으로 열린다. 플레이어의 선택 댓글이 먼저 나타나고 잠시 후 상대의 대댓글이 자동으로 달린다.

## 5. 매장관리와 영업 종료

- 가게 관리 앱을 열면 매장봇의 환영 메시지와 오늘의 만족도·후기 안내가 순서대로 도착한다. 아래 \[확인하기\]를 누르면 당일 손님 게시글과 영수증 연출로 이동하여 팔로워·별 증가를 재연한다.
- 후기 본문은 펼친 상태로 보여주고 댓글은 표시하지 않는다.
- 후기의 수치 연출은 자동으로 진행하되 다음 후기는 플레이어 입력 후 이동한다.
- 방문 완료 시 지급한 팔로워를 다시 지급하지 않는다. 앱 재방문과 정산 재생에도 보상이 중복되지 않는다.
- 매장관리 정산을 <b>끝까지 본 뒤</b> 영업 종료를 누르면 달력으로 이어진다.
- 정산을 보지 않고 영업 종료를 누르면 정산을 먼저 재생한 뒤 달력으로 이어진다.
- 기존 이틀 시연과 DAY 3 업그레이드 감상 흐름을 유지한다. 실제 3일차 플레이는 추가하지 않는다.

## 6. UI와 후기 원본

보내준 분홍색 픽셀 핸드폰, 리본·해골 장식, 프로필·장소·사진·반응 아이콘·본문의 배치를 기준으로 한다. 원본 후기 이미지 중 머리가 비어 있는 그림은 손질 결과와의 합성을 염두에 둔 자료로 구분한다.<br /><mention url="https://app.notion.com/p/403648bf6778803c987fe9ac906a6fe3" />

- 취준생 좀비, 샌즈, 마왕 부하 각각 미용 성공 / 미용 실패 & 야차 승리의 두 후기를 사용한다.
- 마왕 부하의 동료 댓글 두 문장은 원문에 이미 포함된 고정 댓글이다.
- 좀비 계정은 UI의 Duduk\_zom과 노션의 Dubuk\_zom이 다르다. 시연에서는 후기 본문 출처인 노션 표기를 임시 적용하며 최종 표기는 확인이 필요하다.

## 후속 피드백 반영 · 로컬 0.31

핸드폰 홈을 바탕화면과 상태 표시줄(시각·통신·Wi-Fi·배터리)로 구성하고 몬스타그램/가게 관리 아이콘을 같은 규격으로 맞췄다. 상태 표시줄은 게임용 장식이며 실제 장치 상태를 읽지 않는다. 오른쪽 안내 문구는 없애고 우측 하단 영업 종료 버튼만 남긴다.

일반 게시글에 1·2일차 오늘의 운세 초안을 추가했다. 화면에 실제로 보인 글 또는 댓글을 연 글을 읽음으로 기록하고, 다음 날 새 글 뒤·지난날 본 글 앞에 ‘여기까지 확인했어요’를 표시한다. 선택·자유 댓글·읽음 기록은 같은 본편의 다음 날에 이어지고 새 플레이에서는 초기화된다.

기존 자유 입력 없음/선택 후 수동 댓글 열기 검토안은 이번 사용자 요청으로 위 4절의 규칙으로 변경했다. 로컬 빌드와 86개 단위·데이터 검사, Chromium에서 아이콘 규격·자동 댓글 순서·자유 댓글·매장봇 확인·2일차 읽음 구분과 댓글 유지를 확인했다. 공개 배포·Unity·Excel 변경은 하지 않았다. 실제 화면은 docs/local-0.31에 보관한다.

## 후속 수정 · 로컬 0.32

정산의 다음 후기·정산 확인 완료 버튼을 영수증 오른쪽 빈 공간으로 이동한다. 영수증과 버튼이 겹치지 않게 간격을 둔다.

운세는 미용실 원장 중심의 이야기가 아닌, 상황을 상상하고 세 가지 중 하나를 고르는 방식으로 변경했다. 1일차는 ‘당신은 달빛이 비치는 길을 걷고 있다. 골목 끝에서 처음 보는 무언가를 발견했다. 무엇을 보았는가?’이며, 혼자 빛나는 푸른 꽃 / 주인 없이 놓인 작은 열쇠 / 나를 기다리는 듯한 검은 고양이 중에서 선택한다. 2일차는 숲속에서 발견한 문 너머의 풍경을 고른다. 선택 댓글이 먼저 달리고 해당 선택의 운세 해석이 대댓글로 이어진다. 문장과 해석은 시연용 초안이다.

로컬 빌드·86개 검사와 Chromium의 자동 댓글 및 1440/900px 화면 비겹침 검사를 통과했다. 실제 화면은 docs/local-0.32에 보관했다. 공개 배포는 하지 않았다.

## 후속 수정 · 로컬 0.33

홈의 몬스타그램 앱에 읽지 않은 게시글이 있으면 N 배지를 표시한다. 일반 글·운세·손님 후기를 포함하며, 앱을 열기만 해서는 지워지지 않는다. 기존 읽음 기록을 기준으로 모두 확인한 뒤 홈에 돌아오면 사라지고 다음 날 새 글이 있으면 다시 나타난다.

가게 관리 안내는 첫 환영 메시지 → 1초 뒤 만족도·후기 안내 → 다시 1초 뒤 확인하기 버튼 순서로 표시한다. 버튼에도 짧은 등장 움직임을 적용했다.

로컬 빌드와 기존 86개 검사를 통과했다. Chromium에서 N 유지·해제와 메시지/버튼 순서·간격, 도중 홈 이동 시 이전 예약 출력 차단을 확인했다. 공개 배포는 하지 않았으며 실제 화면과 검증 설명은 docs/local-0.33에 보관한다.

## 후속 수정 · 로컬 0.34

손님의 부탁을 읽을 여유를 주기 위해 형태·그리기·붙이기의 최초/상세 부탁 말풍선은 기존의 절반 속도로 재생한다. 개발실의 부탁 대사 미리보기도 같은 속도로 맞춘다. 문장 바로 보기와 직접 다음 문장으로 넘기는 입력은 유지한다.

## 후속 수정 · 로컬 0.35

가게 관리에서 확인하기를 누른 뒤의 손님 후기 핸드폰을 몬스타그램과 같은 분홍색 원본 핸드폰으로 통일한다. 리본·해골 장식, 노치, 시각·통신·배터리 상태 표시줄, monstagram 제목, 홈·뒤로 버튼을 같은 UI 구성으로 사용한다. 영수증과 오른쪽 정산 진행 버튼은 기존 위치를 유지한다.

후기는 같은 핸드폰 화면 안에서 위로 이동하고 팔로워 집계를 재연한다. 긴 후기 본문은 내부 스크롤로 읽을 수 있다. 홈·뒤로 버튼으로 중간에 나오면 정산 완료로 처리하지 않으며 다시 가게 관리에서 확인할 수 있다. 이미 지급한 팔로워를 다시 지급하지 않는다. 이번 변경은 로컬 검토본이며 공개 배포는 하지 않았다.

## 후속 수정 · 로컬 0.36

날씨를 홈 화면의 비조작 위젯 카드로 묶는다. ‘오늘의 날씨’ 제목, 밤 기온, 구분선 아래 낮 기온을 하나의 둥근 블록에 배치하고 배경·테두리·옅은 그림자를 적용한다. 사용자가 바탕화면에 위젯을 배치한 느낌이며 클릭하거나 드래그하는 기능은 없다. 기존 기온 범위와 일차별 유지 규칙은 그대로다.

## 후속 수정 · 로컬 0.37

영수증 정산 화면의 핸드폰 홈·뒤로 버튼은 전체 정산 화면에서 비활성화한다. 집계 중이나 다음 후기 입력을 기다리는 중에도 연출을 중단하지 못한다. 0.35의 중간 홈 복귀 허용 결정은 이번 요청으로 변경한다.

가게 관리에서 시작한 정산의 마지막 버튼은 ‘정산 확인 완료’ 대신 ‘홈으로 돌아가기’로 표시한다. 영업 종료를 먼저 눌러 미확인 정산을 거치는 기존 흐름은 다음 날로 이어지므로 그 경우에는 목적지에 맞게 ‘다음 날로’로 표시한다.

손님의 최초·상세 부탁에서 선택지가 나타난 뒤에는 F·Enter·Space와 미용실 iframe의 다음 대사 입력으로 선택을 실행하지 않는다. ‘네?’와 ‘알겠습니다’는 화면의 해당 버튼을 직접 클릭해야 진행한다. 문장 출력 중 바로 보기와 선택지 이전의 다음 문장 입력은 유지한다. 미용 튜토리얼을 다시 켠 것은 아니다. 로컬 검토본이며 공개 배포는 하지 않았다.

## 후속 피드백 반영 · 로컬 0.38

<date start="2026-10-25" /> · 공개 미반영 · 로컬 검토 후 배포 및 프로그래머 전달 정리 예정

1. 이미 들은 미용 1·2·3단계로 다시 이동하면 손님의 부탁 메모 글자만 타이핑한다. 글자당 28ms, 항목 사이 100ms로 빠르게 확인한다. 첫 부탁의 말풍선·줌인/줌아웃·UI 순차 등장은 유지하며 왕복 때 반복하지 않는다. 빠른 전환에서는 이전 단계 타이핑을 취소한다.
2. 영업 종료 후에는 홈 대신 가게 관리 앱을 자동으로 연다. 환영 메시지 → 후기 안내 → 확인하기의 순차 표시는 유지한다.
3. 정산 마지막 ‘홈으로 돌아가기’로 복귀하면 읽지 않은 일반 글·후기가 있는 몬스타그램에 N을 표시한다. 정산 전에 N을 먼저 보여 주지는 않는다.
4. 그날 정산을 완료한 가게 관리에 재진입하면 오늘 증가량·누적 팔로워와 완료 안내를 보여준다. 영수증을 다시 재생하지 않는다. 다음 날의 새 정산은 별도로 진행한다. 영수증 중 홈·뒤로 잠금과 이미 지급한 보상의 중복 방지는 유지한다.
5. 날씨 홈 위젯을 일차별 팔로워 증가 막대 차트·누적 팔로워·다음 스타까지 남은 수로 교체한다. 실제 방문 완료 기록을 합산한다. 현재는 1스타 5,000명까지 표시하고 달성 뒤 ‘1스타 목표 달성’으로 바뀐다. 2스타 기준은 미정이다. 비조작 위젯이며 본편 낮 기온 표시는 유지한다.
6. 손질 직후 만족에는 꽃 7개와 상승음, 불만족에는 카메라 흔들림과 하강음을 더한다. 같은 반응을 빠르게 반복할 때는 550ms 간격을 두고 반대 반응은 즉시 전환한다. 기존 900ms 뒤 중립 복귀와 최종 종합 평가를 유지한다. 효과음은 시연용 합성음이며 소리 끄기를 따른다.
7. 선택지가 없는 가벼운 일반 글을 1일차에 유령 빨래방·슬라임 제과점, 2일차에 늑대인간 산책·박쥐 퇴근 각 2개씩 추가한다. 기존 선택형 세계관 글과 상황 선택 운세도 함께 둔다.
8. 좀비·샌즈·마왕 부하의 미용/야차 후기마다 가벼운 댓글 선택지 2개와 손님의 대댓글 초안을 추가한다. 선택하면 하단 댓글창이 자동으로 열리고 내 댓글 다음으로 답글이 달린다. 기존 후기 본문은 유지한다. 일반 글과 후기의 선택·자유 댓글·읽음은 같은 본편의 다음 날에도 이어진다. 원문 없는 결과는 임의로 채우지 않는다.

좀비는 ‘오늘 하루는 머리 감으시면 안 돼요!’에 이미 감아버렸다고 답하고, 샌즈는 ‘뼈 있는 후기’에 살이 없어서 살살은 어렵다고 답한다. 마왕 부하는 휴가 중 알림을 껐더니 연락용 박쥐가 창문을 두드렸다고 답한다. 후일담 문장은 검토용이며 사용자 후기 원문과 구분한다.

빌드·88개 단위/데이터 검사와 Chromium의 새 흐름·실제 손질 반응·오디오 시작/무음, 본편 완료 기록 전달 시 이전 댓글 복원을 확인했다. 기존 정산 회귀는 Chromium/WebKit 통과. 실제 Safari·Unity·전체 본편 전투 완주 검증은 아니다. 공개 0.37과 프로젝트 v15·Excel·전투 수치는 유지한다.
