변경 의도: 업무에 치여 뿔이 세 눈을 위협하는 마왕 부하에게, 무성한 가지를 크게 걷어낸 뒤 작은 뿔 한 쌍을 지키는 손질 경험을 만든다. 발모제는 잘못 깎은 뿔을 원래 자리에서 복구하는 도구로 사용한다.
버전: 통합 웹판 0.14 · 마왕 부하 미용 시험
날짜: 2026-10-16 (한국 시간)

수정 요약
- 개발실 → 미용 수정 → 마왕 부하 → 이 설정으로 미용 시험. 본편 방문 순서와 야차는 미연결.
- 제공 원본 17개를 내용 변경 없이 연결했다. 등장/목표 원화와 앞뒤 4프레임 걷기 비교를 추가했다.
- 얼굴·눈·입과 손질할 뿔을 분리했다. 망치·정은 뿔만 깎으며, 발모제는 원본 뿔 픽셀과 설정 범위가 겹치는 곳만 복구한다.
- 기존 trim/preserve 판정과 영역·오차·배점을 사용한다. 만족 반응은 두 요구가 모두 충족될 때만 나온다. 작은 뿔을 절반 미만으로 남긴 경우에는 불만족이다.
- 대사는 사용자 캐릭터 설정을 바탕으로 작성한 시험용 초안이다. 대사 편집에서 여러 문장과 네? 이후 상세 부탁을 수정할 수 있다.
- 현재 시험 손님의 대사·미용 설정은 프로젝트 JSON에 보관한다. Excel 편집·버전 내보내기에서는 시험 전용 연결을 제외하고, Excel 수정본을 가져오면 원래 시험 대사는 유지한다. ID 충돌 시 기존 Excel 행을 덮어쓰지 않고 시험 대사에 새 ID를 연결한다.
- 과거 JSON을 불러오면 기존 편집을 유지하면서 없는 미용 시험 손님만 추가한다.
