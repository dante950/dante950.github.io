# 로컬 0.32 · 선택형 운세와 정산 버튼 위치

변경 의도: 영수증을 가리지 않고 다음 행동을 찾게 하고, 미용실 원장이라는 직업에서 벗어나 누구나 상상하며 참여할 수 있는 운세를 만든다.

- 후기 진행·정산 확인 버튼을 영수증 오른쪽 빈 공간으로 이동했다.
- 1일차는 달빛 아래 길에서 발견한 것, 2일차는 숲속 문 너머 풍경을 상상하는 질문으로 변경했다. 각 질문은 세 선택지와 각각의 댓글·해석 대댓글을 갖는다.
- 기존 댓글 자동 열기·순차 댓글 등록 흐름은 유지한다. 운세 본문과 세 선택지를 읽기 좋게 표시했다.

검증: 로컬 빌드 성공, 기존 단위·데이터 검사 86개 통과. scripts/check-fortune-032.mjs에서 두 운세의 세 선택지별 댓글 연결, 실제 세 번째 선택의 자동 대댓글, 1440/900px 화면에서 영수증과 버튼 비겹침 및 화면 내부 배치를 확인했다. Chromium 페이지 오류 없음.

fortune.png와 receipt-button.png는 이번 로컬 실행 화면 캡처다. 공개 배포와 Safari·Unity 실행 검사는 하지 않았다. Excel 및 전투 로직 변경 없음.
