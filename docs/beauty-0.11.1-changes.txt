변경 의도: 눈코입의 형태를 보호하면서 얼굴 위에 색과 무늬를 그릴 자유를 주고, 플레이어는 만족도 숫자 대신 손님의 표정과 요구사항 체크로 반응을 읽도록 한다.
버전: 통합 웹판 0.11.1 · 얼굴 그리기와 표정으로 보는 반응

실제 변경:
- src/salon-beauty.js / 그리기 가능 범위: 현재 머리·뼈 재료만 → 현재 재료 + 별도 좀비 얼굴의 실제 픽셀. 샌즈의 보호된 눈코입에도 paint/erase를 허용한다. 배경·가운·샌즈의 깎아 없앤 빈 공간은 현재 버전에서 색칠되지 않는다.
- 샌즈 보호 처리: 모든 도구 차단 → 망치·정/발모제 등 형태 변경은 계속 차단하고 색칠/색 지우기만 허용.
- 얼굴 색은 원본 얼굴·표정 위에 별도로 합성한다. 100% 불투명도는 눈코입을 시각적으로 덮을 수 있으나 원본 픽셀과 형태 판정은 변경하지 않는다. 지우면 현재 표정이 다시 드러난다.
- 0.11의 크기 1~30, 불투명도 1~100%, 드래그별 덧칠 유지. 얼굴 색도 되돌리기·지우기·단계 이동·완성 이미지에 반영.
- 되돌리기에서 머리 재료가 없는 얼굴 픽셀의 색까지 잘못 지우지 않도록 허용 범위를 동일하게 적용한다. 머리카락이 없는 좀비 얼굴을 가위로 지나갈 때는 얼굴 색을 지우지 않는다.
- 왼쪽 손님 부탁 메모: 손님 만족도 n/100 행과 숫자 갱신 제거. 체크·취소선·다시 듣기는 유지.
- src/app.js / 시험 결과: '미용 시험 · n점' → '미용 시험 완료'.
- 야차 제안 창: '미용 만족도 n / 100' 문구 제거. 선택지·전환 조건 유지.
- 정산의 손님 행: '손님 · n점' → '손님 · 미용 완료'. 야차 전용 손님 표기와 금액 유지.
- 안내 문구와 버전 표시 수정.

변경하지 않은 계산/데이터:
- 내부 만족도·표정·요구 체크·배점·팁·스토리 분기 계산 유지. 개발실의 배점 설정은 유지한다.
- data/project.json, 이미지 원본, 전투 코드·전투 데이터, 원본 엑셀 변경 없음.
- 얼굴에 색을 칠했다는 이유의 추가 감점 없음.

검증:
- 빌드와 기존 단위 검사 31개 통과.
- Chromium/WebKit에서 두 손님의 얼굴 반투명 색칠·덧칠·되돌리기·색 지우기·불투명 덮기·완성 캡처를 확인. 형태와 판정 보호 마스크 유지 확인.
- 반투명 픽셀 색 비교는 브라우저 캔버스 합성의 채널 반올림 차이 1을 허용하고, 저장된 불투명도와 누적 값은 정확히 비교한다.
- 기존 미용 회귀 검사와 본편 연결 검사에서 숫자 노출 제거를 확인. 공개 배포 확인·실제 캡처는 outputs/beauty-v111-review/에 별도 기록한다.
- 실제 Unity 검증이나 모든 전투 승패 분기의 완주를 뜻하지 않는다.
