변경 의도: 직접 만든 머리와 꾸밈을 손님의 반응으로 돌려주고, 미용 결과를 숫자가 아닌 표정과 분위기로 느끼게 한다. 손질 도움말을 플레이 안으로 들이며 샌즈의 가벼운 손질 요구와 완료 표시 사이의 간극을 줄인다.
버전: 통합 웹판 0.12 · 거울 속 손님의 반응

실제 변경:
- src/salon-beauty.js / '판정 영역'(시험 전용) → '손질 가이드'(본편·시험 공통). 기능은 눌러 켜고 끄는 손질 위치 표시다. 개발자처럼 보이던 점선 버튼을 일반 미용 도구 버튼과 맞췄다.
- src/salon-beauty-result.js / 즉시 결과 전달 → 2.6초 동안 실제 미용실과 완성 손님을 1.24배 줌인 → 결과 표정·효과 → 6.5초에 기존 다음 대사/시험 완료로 연결. 건너뛰기와 계속하기 제공. 중복 입력은 결과를 한 번만 전달한다.
- 만족: 웃는 표정, 따뜻한 가장자리 빛, 여섯 꽃의 등장, 따봉 손 상승. 보통: 일자 입, 담담한 분위기. 불만족: 찡그린 표정과 붉은 그라데이션. 만족도 숫자는 노출하지 않는다.
- 머리/뼈의 실제 손질 결과와 염색·얼굴 그리기·스티커를 현재 캔버스 그대로 확대한다. 참고 GIF는 분석용으로만 읽었고 배포 파일에 복사하거나 재생하지 않는다.
- 샌즈는 제공받은 눈 세 종류와 만족 시 입을 유지한다. 결과의 일자/찡그린 입은 임시 픽셀 표현이다. 원본 PNG는 수정하지 않는다.
- 따봉 손은 Canvas 도형으로 임시 제작했다. 샌즈는 뼈 색·관절·푸른 소매, 좀비는 기존 얼굴에 맞춘 청록색 손으로 표현한다. 원본 그래픽 제작 리소스와 구분한다.
- 미용 시험 완료 창을 작은 오른쪽 아래 카드로 바꾸어 완성 손님을 가리지 않는다.
- 동작 줄이기 설정에서는 줌·꽃 이동·손 이동 없이 표정과 효과를 표시한다.

샌즈 체크 기준 변경 (src/beauty-shape.js):
- 이전: 모든 손질 영역 각각 원본 픽셀 70% 제거.
- 이후: 손질 가능한 목표 픽셀을 합쳐 50% 이상 제거 + 유효 영역의 2/3 이상에서 각각 30% 이상 제거. 기본 6개라면 4개 이상이다. 별도로 설정한 더 쉬운 만점 허용 조건도 인정한다.
- 눈코입 보호로 전부 제외된 목표는 필수 영역 수에서 제외한다. 실제 손질 전에는 완료되지 않으며 한두 큰 영역만 깎아서 달성할 수 없다.
- 안쪽 손상과 기존 눈 덮임의 완료 허용치: 각각 5% → 12%.
- 기존 점수 산식·비례 감점·장식 태그·팁·본편 분기 수치는 변경하지 않았다. 체크를 얻었다고 점수를 만점으로 바꾸지 않는다.

유지한 범위:
- 눈코입 형태 보호, 얼굴 색칠, 불투명도/크기 슬라이더, 원래 머리와 발모제 결합, 커트로 분리된 조각 제거, 대사 최초 1회/다시 듣기, 체크/취소선 유지.
- data/project.json, 원본 Excel, 전투 코드·전투 데이터 변경 없음. 꼰대 엘프 미추가.
- 실제 Unity 실행 또는 모든 전투 승패 분기를 검증한 작업이 아니다.

검증 기록:

- 결과 캡처와 공개 배포 확인은 outputs/beauty-v12-review/에 별도 보관한다.
