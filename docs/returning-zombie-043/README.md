# 성공 좀비 만족도·발모제 항의 변경

2026-11-01. 사용자의 플레이 검토를 위한 웹 적용이며 성공 좀비 미용 Notion 명세는 아직 변경하지 않는다.

- 만족 80점 이상 / 보통 40점 이상 80점 미만은 성공, 불만족 40점 미만만 실패. 머리·치아·장식의 전부 충족을 별도 필수 조건으로 사용하지 않는다. 비중 10/60/30과 각 요구의 점수 계산은 유지한다.
- 최종 표정은 만족/보통/불만족을 그대로 표시하고, 같은 결과로 선택지·퇴장·보상(+1,100/0)을 연결한다.
- 가위가 실제로 머리를 제거한 이력을 방문 동안 기억한다. 그 뒤 발모제 사용은 복구 또는 추가 성장 모두 항의하지 않는다. 빈 곳에 가위를 쓰거나 도구만 선택한 경우는 이력이 생기지 않는다. 새로운 방문은 초기화한다. 기존의 각 항의 1회 규칙은 유지한다.

72개 관련 단위·데이터 검사와 빌드 통과. scripts/check-returning-satisfaction.mjs의 실제 포인터 손질에서 취업 60점 보통 성공 +1,100, 로또 90점 만족 성공 +1,100, 로또 0점 불만족 실패 0을 확인했다. 세 경우의 결과 표정·선택지·퇴장·마감 기록이 일치했다. 가위 사용 후 발모제 무항의, 빈 곳 가위 후 발모제 항의, 새 방문 이력 초기화도 확인했다. 등장/재회 대화는 이 집중 검사에서 건너뛰었다. 전체 본편·Unity·Safari 검증은 아니다.
