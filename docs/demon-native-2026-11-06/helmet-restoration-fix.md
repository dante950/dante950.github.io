# 투구 복원 — 뿔 외곽의 과도하게 엄격한 판정 수정

2026-11-06 사용자가 뿔과 기스를 복원한 화면을 전달했으나 부탁 체크가 켜지지 않았다. 사용자의 진행 중 재료 배열을 직접 읽은 것은 아니며, 같은 유형의 실패를 별도 브라우저에서 재현했다.

기존 구현에서는 도구 크기 4로 목표 뿔을 모두 채우고 기스도 전부 덮어도 실패했다. 뿔 100%, 기스 100%, 투구 훼손 0%, 얼굴 노출 0%인데 외곽 초과율이 30.92%로 계산되어 기존 6% 제한에 걸렸다. 이전 검사는 도구 크기 1로 정확한 목표 픽셀만 채워 이 문제를 놓쳤다.

뿔 목표 외곽의 반경 2개 판정 셀(320×350 좌표계에서는 4px)을 작은 손질 오차로 허용한다. 이를 넘어선 초과 부분에는 기존 6% 제한을 적용한다. 목표 충족률 92%, 기스 96%, 투구 손실 2%, 얼굴 보호/15% 즉시 중단 규칙은 그대로다. 너무 크게 기른 부분은 형태 단계의 손질 가이드에서 빨강으로 표시한다. 원본 이미지, 다른 손님, 2·3페이즈 판정은 변경하지 않았다.

관련 단위 검사 8개와 빌드 통과. Chromium과 WebKit에서 실제 크기 4 포인터 조작으로 뿔 복원 → 기스 덮기 → 부탁 2개 체크 → 2페이즈 전환을 확인했다. 과도한 추가 성장 시 실패하고 망치로 해당 부분을 제거하면 다시 통과하는 것도 확인했다. 점수나 재료 셀을 강제로 설정하지 않았다.

전용 회귀 스크립트는 scripts/check-demon-helmet.mjs다. 기존 마왕 전체 브라우저 검사도 뿔 복원 도구를 1에서 4로 바꾸어 같은 오류를 다시 검출하게 했다. 확인된 초과율은 Chromium 0%, WebKit 약 1.54%로 둘 다 허용 범위다.

기존 열린 탭에는 이전 코드가 남으므로 새 배포 후 새로고침해야 새 판정이 적용된다. 기존 탭의 진행 상태를 복구·이전한 변경은 아니다.
