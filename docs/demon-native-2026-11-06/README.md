# 마왕을 기존 본편 미용실에 통합

2026-11-06 사용자 피드백: 이전 e8a9682 구현은 기존 미용실 안에 별도 게임을 넣었고, 요청하지 않은 시험 야차를 추가했다. 해당 독립 구현을 폐기하고 기존 손님의 흐름에 마왕을 추가했다.

## 변경 결과

- 기존 메인의 손님 선택 → 마왕(10007), 4일차 영업 시작을 사용한다. 별도 마왕 시험 배너와 독립 화면을 제거했다.
- 3스타 방문은 외관 접근·별 확인·입장 → 문 열림 → 주인공과 Mimic 반응 → 발걸음 → 갑옷 팬 → 기존 미용실의 마왕/부하 등장 → 지정 대사 → 착석 → F → 공통 미용 화면이다.
- 0/1/2스타는 별 개수에 맞는 대사 후 오른쪽으로 지나치고 GAME OVER다. 외관은 제공된 Notion 콘티의 그림을 활용한 임시 연출이다. 최종 원화/전용 프레임 애니메이션으로 설명하지 않는다.
- 미용실 배경·이동·대화창·포스트잇·도구·3단계 탭·팔레트·스티커·결과 반응은 기존 salon.html/salon-beauty 런타임을 사용한다.
- 1페이즈: 발모제와 망치·정으로 뿔 복원, 투구 기스 덧칠. 귀 없는 미형 얼굴을 투구 아래 둔다. 얼굴 손질 첫 두 번 경고, 지정 영역 15% 이상 노출 시 즉시 중단.
- 2페이즈: 귀/긴 머리 정리, 검정 염색, 얼굴에 남은 색 0, 스티커 0. 자르기 힌트 항의는 없다. 색·얼굴·스티커 항의는 재출력 간격을 두고, 지우기/제거로 고칠 수 있다. 최종 완성 때 분기한다.
- 2페이즈 성공에서 성공 경로가 확정된다. 고블린 본모습의 3페이즈는 모든 스타일·무손질 완성을 허용한다. 가위는 머리카락, 망치·정은 돌만 깎고 항의/실패는 없다.
- 꾸민 고블린의 모습을 그대로 기존 미용실에 두고 단체사진과 미용 성공 안내로 끝난다. 현실 귀환·몬스타그램의 최종 엔딩 연출 전체는 구현하지 않았다.
- 미용 실패는 야차 신청 대사 후 미용 재시작/메인 선택까지만 제공한다. 마왕 전투·HP·공격 패턴·시험 전투·야차 재도전은 제거했고 기존 몬스터 전투는 유지한다.

## 연결과 보존

src/demon/ 독립 화면·모델·스타일, public/demon-assets.json 및 기존 독립 게임 검사를 삭제했다. demon.html은 본편 마왕 손님으로 이동시키는 호환 주소만 남긴다.

본편 3일차 마감에서 실제 스타·팔로워·완료 기록을 인계한다. 마왕부터 직접 시작하면 3스타 조건/팔로워 0명/이전 기록 없음이며 메뉴에서 이를 알린다. 기존 시험 스타 기준 5000/5500/6100은 변경하지 않았다.

제공 PNG 원본은 수정하지 않았다. 실행 중 레이어 배치·마스크·돌과 머리의 분리를 사용한다. 원본 Excel, Unity 계약, 전투 전용 실험실은 수정하지 않았다. 마왕은 현재 웹 전용 손님이며 단계별 런타임 연결을 실제 Unity 검증이나 확정 Excel 계약으로 설명하지 않는다.

## 검증

관련 단위·데이터 검사 63개 통과. 기존 손님 데이터는 그대로이며 새 손님/대사 연결/4일차 일정만 추가했다.

브라우저 검사:
- scripts/check-demon-salon.mjs: 실제 포인터 투구 복원 → 미형 커트·검정 염색 → 자유 미용 → 사진. 얼굴 한 픽셀 칠하기/지우기, 스티커/제거, 가위/망치 재료 분리, 즉시 실패·재시작, 별 0/1/2 분기, 실제 마감 iframe 메시지 인계.
- scripts/check-demon-salon-regression.mjs: 기존 좀비·샌즈·마왕 부하의 미용실/대화/미용 진입, 2페이즈 실패에서 고블린 미공개·전투 미진입, 2스타 자연 지나침, 페이즈 전환 중 메인 복귀.
- 완료 상태 주입은 테스트 서버 전용 fixture다. 미용 성공 경로에서는 점수/재료를 주입하지 않고 실제 포인터로 조작한다. 전체 1~3일차 완주나 Unity 실행 검증은 아니다.

검사 과정에서 숨겨진 따봉 이미지가 미용 캔버스 일부의 입력을 가로채던 문제를 수정했다. 장식 이미지는 pointer-events:none으로 입력 대상에서 제외했다. 브라우저별 대사 전환 사이를 검사기가 기다리도록 보완했으며 제품의 대사를 생략하거나 강제 성공시키지 않았다.

Chromium과 WebKit에서 두 브라우저 검사를 통과했다. 이전 손님 데이터·대사·1~3일 일정 보존을 JSON 값으로 대조했다. 공개 배포 결과는 GitHub Actions와 공개 version.json으로 별도 확인한다.
