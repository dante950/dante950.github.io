# 야차 결과 화면 · 스타 유지

2026-10-31

사용자 제공 시안과 원본 PNG를 그대로 사용했다. 승리는 주인공 왼쪽, 패배는 상대 오른쪽과 작은 좌측 하단 선택지다. A/D 선택, F/Enter 확정, 마우스 선택을 지원하고 선택된 버튼에만 설명을 표시한다. 마왕 부하·커피 튜토리얼 패배는 재도전만 허용한다.

본편 일반 손님 미용 실패 후 패배 인정 시 -100을 1회 정산한다. 미용 성공 후 패배는 현재 기본 보상을 유지하며 안내는 실제 증감량을 쓴다. 재도전은 기록·팔로워를 변경하지 않는다. 기존 최고/중간 보상 수치와 일정은 유지했다. 네오위즈/크로니클 전체 수치안과 3일차 재등장·4일차 마왕은 아직 이 변경의 구현 범위가 아니다.

스타 획득 이력과 실제 팔로워의 보호 하한을 마감 iframe 왕복에 보존한다. 이미 달성한 최고 스타의 기준보다 낮아질 감소는 실제 팔로워 수를 해당 기준에 고정한다. 기준선 위에서 이루어지는 증감은 원래 수치를 적용한다. 별 진행률과 외관도 유지한다. 3스타는 유지하고 최대 진행률로 표시한다. 실제 공개판은 기존 1스타 기준 5000 및 2일차 판정을 유지하며 2/3스타 기준과 외관 리소스는 전체 밸런스 적용 시 연결한다. 2100→3000→4000은 사용자 예시를 검증하는 테스트 전용 값이다.

초기 구현 검증(실제 팔로워가 기준 아래로 감소하던 계산은 아래 정정으로 폐기): 관련 단위/정산 29검사, 빌드, 실행 JS 구문 검사 통과. Chromium에서 A/D 선택·F 확인, 선택 설명, 본편 결과 콜백을 통한 -100 단일 정산, 마왕 부하 계속 버튼 없음, 영수증 2200→2000 감소 시 1스타·외관 유지와 11%→0%, 2100까지 0% 및 2200 회복 시 11% 확인. 본편 연결 검증은 전투 완료 이벤트 대입이며 실제 전투 전체 완주·Unity·Safari 검증은 아니다.

## 실제 팔로워 하한 정정

사용자 설명을 진행률 표시만 보호하는 것으로 잘못 해석한 부분을 수정했다. 1스타 2100명 획득 후 2200−200은 실제 2100명, 2150−100은 실제 2100명/실제 감소50명, 기준선에서 추가 감소는0명이다. 보호된 감소분을 이월하지 않는다. 미획득 스타는 보호하지 않고, 기준선 위의 증감과 양수 보상은 그대로 유지한다. 결과 안내와 최종 기록은 같은 계산을 쓰고 영수증은 실제 증감량 및 보호량을 표시한다.

관련32검사와 빌드, Chromium에서 본편 결과 콜백 대입→50명 감소 안내→실제2100명·기록1회 및 기준선의0명 감소 안내를 확인했다. 실제 영수증에서2100명/−50명/진행률0%/50명 감소 방지 표시도 확인했다. 전체 보상표·방문 구성 변경은 없다.
