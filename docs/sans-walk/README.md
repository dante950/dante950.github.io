# 샌즈 등장·퇴장 걷기

2026-11-01 (한국 시간). 제공한 몸통/머리 Front·Back 4개 PNG를 바이트 변경 없이 연결했다. 340×153 셀 8장, 프레임당 100ms. 원본의 투명 여백만 화면 합성 시 잘라 표시한다.

입장은 기존 경로를 따라 뒷모습으로 걷고 착석한다. 퇴장은 앞모습으로 2.2초 걷고 사라진 다음 기존 마감으로 이어진다. 미용 결과 얼굴·장식은 몸통의 머리 상하 움직임에 맞춰 합성한다. 샌즈 승리에서 퇴장을 생략하던 분기도 같은 배웅으로 연결했다. 미용 요구·대사·점수·보상·다른 손님의 흐름은 변경하지 않았다.

빌드와 scripts/check-sans-walk.mjs의 Chromium 검사를 통과했다. 실제 손님 선택과 입장, 걷기 이미지 변화, 승리/패배 결과 후 대사·선택·앞모습 퇴장, departed 1회와 마감 진입을 확인했다. 미용·전투 완료 결과를 대입한 집중 검사이며 전체 전투 완주·Unity·Safari 검증은 아니다. arrival.png와 departure.png는 실제 실행 캡처다.
