# 4일차 마왕 — 기존 본편 미용실에 통합

2026-11-06 사용자 수정 요청에 따라 별도 마왕 게임과 클릭·긁기 시험 야차를 폐기했다. 현재 구현과 검증 기록은 [기존 미용실 통합 기록](demon-native-2026-11-06/README.md)을 기준으로 한다.

- 본편의 손님 선택에 마왕(10007)이 포함된다. 직접 시작은 3스타 조건이며 팔로워 0명, 이전 손님 기록 없음이다.
- 3일차 정산에서 이어지는 경우 실제 팔로워·기록·스타를 유지한다.
- 외관의 별 확인 → 입장 컷씬 → 기존 미용실에서 등장 대화·착석·F 상호작용 → 공통 미용 화면을 사용한다.
- 1페이즈 투구 복원 → 2페이즈 미형 미용 성공에서 성공 경로 확정 → 3페이즈 고블린 자유 미용으로 이어진다.
- 마왕 야차는 구현하지 않는다. 미용 실패/얼굴 15% 노출 시 야차 신청 대사와 미용 재시작·메인 선택까지만 진행한다.
- 과거 demon.html은 본편 마왕으로 이동하는 호환 주소다. 독립 게임이나 별도 미용 UI는 없다.
- 최종 현실 귀환·몬스타그램 연출은 아직 구현하지 않았다. 기존 미용실의 단체사진과 성공 안내까지 연결했다.
