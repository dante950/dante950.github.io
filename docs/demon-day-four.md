# 4일차 마왕 방문 · 공개 플레이테스트

- 본편 3일차 정산 후 4일차 영업 시작. 획득한 별 0/1/2는 지나침 → GAME OVER, 3은 입장.
- /demon.html 은 기록을 바꾸지 않는 분기/미용 시험 진입점.
- 마왕 원본 T_Adversary_Phase1, Mimic, 사용자가 지정한 1/2/3페이즈 PNG를 사용.
- 외관은 기존 공개 PT의 미용실 그림을 배치한 임시 장면. 최종 외관 파일이 들어오면 교체.
- 1페이즈: 뿔 복원, 기스 덧칠. 투구 아래 귀 없는 얼굴. 지정 얼굴 영역 15% 노출 시 야차.
- 2페이즈: 귀/긴 옆머리 커트, 검정 염색, 얼굴 그리기 잔여 픽셀 0. 커트 안내 항의 없음. 색/얼굴/스티커 항의는 5.5초 간격.
- 2페이즈 성공 후 성공 경로 확정. 3페이즈는 자유 미용, 실패/항의 없음. 가위는 머리, 망치·정은 돌.
- 야차는 세 페이즈의 클릭/긁기 시험 전투. 패배 시 야차 또는 미용 재도전, 팔로워·스타 변화 없음.
- 별 기준은 공개판의 1스타 5,000명을 유지한 임시 밸런스 [5,000, 5,500, 6,100]. 2/3스타 수치는 확정 기획값이 아니며 조정 대상.
- source PNGs are unmodified. Layer registration and pixel tools are performed at runtime.
- Validation: tests/demon.test.mjs, scripts/check-demon.mjs (Chromium/WebKit).
