# 플레이하는 포트폴리오

크래프톤 인턴 지원용 게임형 포트폴리오를 제작하는 독립 작업 공간입니다.

- 제출 목표: 2026년 10월 22일 24:00 (한국 시간)
- 저장소: https://github.com/dante950/dante950.github.io
- 작업 브랜치: `portfolio`
- 현재 단계: 프로젝트 준비. 포트폴리오 화면과 배포 설정은 아직 만들지 않았습니다.

## 기존 야차차와의 관계

`portfolio`는 기존 `main`과 커밋 이력을 공유하지 않는 독립 브랜치입니다.
야차차 코드, 이미지, 의존성, 빌드 결과물, 배포 작업을 가져오지 않았습니다.
기존 야차차는 `main`에 보존하며 이 작업 공간에서는 수정하지 않습니다.

현재 공개 주소 https://dante950.github.io/ 와 GitHub Pages 배포 설정은
포트폴리오가 완성될 때까지 유지합니다. 이 브랜치에는 자동 배포 작업이 없습니다.
`portfolio`의 변경을 `main`으로 병합하지 않고 별도로 개발합니다.

## 이후 배포와 작품 연결

포트폴리오 완성 후 메인 주소를 전환할 때 배포 구성을 별도로 준비합니다.
야차차 이동 버튼을 넣으려면 야차차가 실행되는 별도 공개 주소를 먼저 마련합니다.
예를 들어 별도 `yachacha` 저장소를 GitHub Pages에 배포하면
`https://dante950.github.io/yachacha/` 같은 주소를 사용할 수 있습니다.
이 주소는 계획 예시이며 아직 생성하거나 연결하지 않았습니다.

`main` 브랜치 보관만으로 별도의 게임 실행 주소가 생기지는 않습니다.

## 작업 원칙

- 포트폴리오에 필요한 파일과 의존성만 추가합니다.
- 기존 야차차의 배포 규칙이나 대용량 자산을 복사하지 않습니다.
- 인증 정보와 개인 제출 서류는 저장소에 넣지 않습니다.
- UI 구현과 빌드 도구는 포트폴리오의 구성과 요구 사항을 정한 뒤 추가합니다.
